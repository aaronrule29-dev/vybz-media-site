VYBZ MEDIA — STATIC PORTFOLIO WEBSITE

FILES
index.html — content and structure
styles.css — responsive design and visual styles
script.js — mobile menu and current year
assets/ — portfolio images and favicon

QUICK PREVIEW
Double-click index.html to preview locally. The web font needs internet; fallback fonts work offline.

PUBLISH FOR FREE (CLOUDFLARE PAGES)
1. Extract the ZIP file.
2. Go to https://dash.cloudflare.com/ and sign in or create a free account.
3. Open Workers & Pages, then Pages / Create application (labels may change).
4. Choose the direct upload / drag-and-drop option.
5. Upload the entire extracted vybz-media-site folder (or a ZIP if the upload UI supports it).
6. Deploy and open the provided *.pages.dev address.
7. Check the website on your phone and click every navigation and contact link.

ALTERNATIVE (NETLIFY DROP)
1. Extract the ZIP.
2. Go to https://app.netlify.com/drop and sign in if required.
3. Drag the entire extracted folder into the drop zone.
4. Open the generated site URL and test it.

EDIT YOUR WORK
Replace assets/nike-run-further.webp and assets/nike-football.webp with new images of the same names, or edit image paths in index.html.
FORGE and ATHENA are intentionally marked in development, not shown as completed case studies.
To add projects, duplicate an <article class="project">...</article> inside the project-grid in index.html.

CONTACT
All contact buttons currently link to https://www.instagram.com/vybzmedia_/
Update these links in index.html if your Instagram handle changes, or switch to mailto:you@example.com when you have a business email.
